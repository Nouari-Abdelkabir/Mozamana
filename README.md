# 🕌 مزامنة — منصة تقسيم التلاوات القرآنية  

> **تطبيق ويب محلي لتقسيم التلاوات القرآنية وتزامنها مع النص القرآني بدقة عالية، مع دعم كامل للروايات المختلفة وألوان التجويد.**

---

## 📖 نبذة عن التطبيق

**مزامنة** هو تطبيق ويب يعمل محلياً على حاسوبك، يتيح لك:

- 🎧 **تقسيم التلاوات القرآنية** حسب الآيات بدقة
- 📝 **تعديل التوقيتات يدوياً** بزر واحد
- 🎨 **عرض النص القرآني** بألوان التجويد (c1 إلى c26)
- 🎙️ **دعم 33 قارئاً** و **22 رواية** قرآنية
- 💾 **حفظ التوقيتات** في ملفات JSON منظمة
- 📤 **تصدير التوقيتات** بصيغ متعددة (JSON / SRT / VTT)
- 🌐 **العمل من السيرفر** أو **من ملف صوتي محلي**

---

## 🎯 الفكرة الأساسية

التطبيق يساعد على:

1. **توليد توقيتات تقريبية** لكل آية (80% دقة) بناءً على عدد الكلمات
2. **تصحيح التوقيتات يدوياً** أثناء الاستماع للتلاوة
3. **حفظ التوقيتات النهائية** في ملفات JSON منظمة
4. **استخدام هذه التوقيتات** في برامج أخرى (مشغلات، تطبيقات، إلخ)

---

## ✨ المميزات

### 📚 دعم واسع للروايات والقراء

- **22 رواية قرآنية**: حفص، ورش، قالون، الدوري، السوسي، البزي، قنبل، شعبة، خلف، خلاد، وغيرها
- **33 قارئاً مشهوراً**: مشاري العفاسي، محمود خليل الحصري، عبد الرشيد صوفي، أحمد ديبان، وغيرهم
- **114 سورة** كاملة

### 🎨 واجهة عربية أنيقة

- تصميم عصري بلونين (نهاري / ليلي)
- خط `NouariAbdelkabir` المخصص للقرآن
- ألوان التجويد الكاملة (26 لوناً)
- أيقونات واضحة

### 🔧 أدوات تحرير متقدمة

- **شريط تقسيمات بصري**: كل آية شريط نسبي لمدتها
  - 🟢 **أخضر**: لم تُقطَع بعد
  - 🔵 **أزرق**: مقطوعة ومثبّتة
- **زر [✂️ اقطع هنا]**: يُسجّل نهاية الآية الحالية
- **زر [▶️ معاينة]**: يشغّل المقطع للتأكد
- **إعادة التوزيع الذكية**: تُوزّع الآيات المتبقية تلقائياً
- **مؤشر أحمر**: يُظهر موقع التشغيل الحالي

### 🔍 زوم على الآية الحالية

- انقر على أي آية في الشريط
- اضغط **[+]** لتكبيرها (1.5× → 2× → 3× → 5×)
- الآية الحالية تُبرز بإطار ذهبي
- الأشرطة الأخرى تبقى بأحجامها

### 📤 تصدير متعدد
  
  - **JSON**: للاستخدام في التطبيقات
  - **SRT**: للترجمات والوسائط
- **VTT**: لتشغيل الفيديو على الويب
